# MagicSchool Email Generator

A standalone HTML email generator for creating professional PD confirmation emails.

## Features

- **Live preview** — See your email as you type
- **Multi-session support** — Add as many sessions as needed
- **Virtual & In-Person** — Toggle between formats
- **Auto-formatting** — Dates, facilitator headers, and layouts handled automatically
- **One-click copy** — Copy HTML directly to Gmail or Outlook
- **No dependencies** — Pure HTML/CSS/JavaScript, works offline

## Quick Start

1. **Download** `index.html` to your computer
2. **Double-click** to open in your browser
3. Fill in recipient, organization, and session details
4. **Copy HTML** button copies the email ready to paste

## GitHub Pages Setup (Optional)

To host this online:

1. Fork or create a new GitHub repo: `magicschool-email-generator`
2. Upload `index.html` as your main file
3. Go to **Settings** → **Pages**
4. Set source to `main` branch
5. It'll be live at `yourusername.github.io/magicschool-email-generator`
